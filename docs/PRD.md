# WeakNet 产品需求文档

## 产品定位

面向移动端测试人员和开发者的网络工具 App，核心能力：**弱网模拟** + **网络诊断** + **实用工具**。
目标市场以墨西哥为主，兼顾通用场景。

---

## 模块一：弱网模拟（已完成）

通过本地 VPN 拦截流量，模拟各种弱网环境，无需 root。

### 功能清单

| 功能 | 状态 | 版本 |
|------|------|------|
| VPN 模式弱网模拟（延迟/抖动/丢包/限速） | 已完成 | v1.0.0 |
| 通用预设场景（正常/弱WiFi/弱4G/2G/地铁/断断续续/断网等） | 已完成 | v1.2.3 |
| 墨西哥预设场景（墨城4G/跨境US/弱信号/雨季/农村） | 已完成 | v1.1.0 |
| 自定义参数（延迟/抖动/丢包/限速自由配置） | 已完成 | v1.0.0 |
| 应用过滤（指定 app 生效，其他不受影响） | 已完成 | v1.0.0 |
| 实时统计（上行/下行/丢弃/延迟包数） | 已完成 | v1.0.0 |
| 场景分类展示 + 参数说明弹窗 | 已完成 | v1.1.0 |
| 启动页 + 版本号管理 | 已完成 | v1.1.1 |
| 切换场景立即生效（清空延迟队列） | 已完成 | v1.2.2 |

## 模块二：网络诊断（已完成基础版）

一站式网络检测工具，帮助用户快速定位网络问题。

### 功能清单

| 优先级 | 功能 | 说明 | 状态 | 目标版本 |
|--------|------|------|------|----------|
| P0 | 网络信息 | 当前 IP（公网/内网）、运营商、WiFi/移动网络类型 | 已完成 | v1.2.0 |
| P0 | Ping 测试 | 输入域名/IP，测延迟（min/avg/max）、丢包率、延迟趋势图 | 已完成 | v1.2.0 |
| P1 | DNS 查询 | 解析域名，支持指定 DNS 服务器（Google/Cloudflare/OpenDNS） | 已完成 | v1.2.0 |
| P1 | 网速测试 | 下载/上传速度测试，实时速度曲线，最终结果汇总 | 待开发 | v1.4.0 |
| P2 | Traceroute | 路由追踪，显示到目标的每一跳 IP、延迟 | 待开发 | v1.4.0 |
| P2 | 端口检测 | 检查目标服务器指定端口是否可达及响应时间 | 待开发 | v1.4.0 |
| P2 | SSL 证书检测 | 查看 SSL 证书信息（颁发者/到期时间/有效状态） | 待开发 | v1.4.0 |
| P3 | 连通性报告 | 一键检测常用服务可达性（Google/WhatsApp/YouTube 等） | 待开发 | v1.5.0 |

## 模块三：TOTP 验证器（v1.3.0 开发中）

| 优先级 | 功能 | 说明 | 状态 | 目标版本 |
|--------|------|------|------|----------|

| P1 | 导出/导入 | 加密导出账号到文件，支持从文件恢复（防卸载丢失） | 待开发 | v1.3.x |
| P2 | 账号分组 | 按发行方分组展示 | 待开发 | v1.3.x |
| P2 | 排序/拖拽 | 自定义账号顺序 | 待开发 | v1.3.x |
| P3 | 云同步 | 可选的云端备份 | 待开发 | 未定 |

## 技术栈

- 语言：Kotlin
- UI：Jetpack Compose + Material Design 3
- 架构：MVVM（ViewModel + StateFlow）
- 弱网：VpnService + NIO Selector + TokenBucket
- 验证器：TOTP (RFC 6238) + EncryptedSharedPreferences + ZXing
- 最低支持：Android 7.0（API 24）
- 编译目标：Android 14（API 34）

# WeakNet 产品需求文档

## 产品定位

面向移动端测试人员和开发者的网络工具 App，核心能力：**弱网模拟** + **网络诊断**。
目标市场以墨西哥为主，兼顾通用场景。

---

## 模块一：弱网模拟（已完成 v1.1.x）

通过本地 VPN 拦截流量，模拟各种弱网环境，无需 root。

### 功能清单

| 功能 | 状态 | 版本 |
|------|------|------|
| VPN 模式弱网模拟（延迟/抖动/丢包/限速） | 已完成 | v1.0.0 |
| 通用预设场景（正常/弱WiFi/4G/3G/2G/地铁/高铁/断网等） | 已完成 | v1.0.0 |
| 墨西哥预设场景（墨城4G/跨境US/弱信号/雨季/农村） | 已完成 | v1.1.0 |
| 自定义参数（延迟/抖动/丢包/限速自由配置） | 已完成 | v1.0.0 |
| 应用过滤（指定 app 生效，其他不受影响） | 已完成 | v1.0.0 |
| 实时统计（上行/下行/丢弃/延迟包数） | 已完成 | v1.0.0 |
| 场景分类展示 + 参数说明弹窗 | 已完成 | v1.1.0 |
| 启动页 + 版本号管理 | 已完成 | v1.1.1 |

## 模块二：网络诊断（待开发）

一站式网络检测工具，帮助用户快速定位网络问题。

### 功能清单

| 优先级 | 功能 | 说明 | 难度 | 目标版本 |
|--------|------|------|------|----------|
| P0 | 网络信息 | 当前 IP（公网/内网）、运营商、WiFi/移动网络类型、信号强度 | 低 | v1.2.0 |
| P0 | Ping 测试 | 输入域名/IP，测延迟（min/avg/max）、丢包率、抖动 | 低 | v1.2.0 |
| P1 | DNS 查询 | 输入域名，解析出 IP 地址，显示解析耗时，支持指定 DNS 服务器 | 低 | v1.2.0 |
| P1 | 网速测试 | 下载/上传速度测试，实时速度曲线，最终结果汇总 | 中 | v1.3.0 |
| P2 | Traceroute | 路由追踪，显示到目标的每一跳 IP、延迟、地理位置 | 中 | v1.3.0 |
| P2 | 端口检测 | 检查目标服务器指定端口（如 80/443/3306）是否可达及响应时间 | 低 | v1.3.0 |
| P2 | SSL 证书检测 | 查看目标域名 SSL 证书信息（颁发者/到期时间/有效状态），支持过期告警 | 中 | v1.3.0 |
| P3 | 连通性报告 | 一键检测常用服务可达性（Google/WhatsApp/YouTube/微信等） | 中 | v1.4.0 |

### 优先级说明
- **P0**：基础功能，第一批开发
- **P1**：重要功能，紧跟 P0
- **P2**：进阶功能，按需排期
- **P3**：锦上添花，有余力再做

## UI 规划

主界面采用底部 Tab 导航：

```
┌─────────────────────────────┐
│                             │
│      （当前 Tab 内容）       │
│                             │
├──────────┬──────────────────┤
│  弱网模拟  │    网络诊断     │
└──────────┴──────────────────┘
```

- **弱网模拟 Tab**：现有的主界面（场景选择、统计、应用过滤）
- **网络诊断 Tab**：工具卡片列表（Ping/DNS/网速/Traceroute 等）

## 技术栈

- 语言：Kotlin
- UI：Jetpack Compose + Material Design 3
- 架构：MVVM（ViewModel + StateFlow）
- 弱网：VpnService + NIO Selector + TokenBucket
- 最低支持：Android 7.0（API 24）
- 编译目标：Android 14（API 34）
